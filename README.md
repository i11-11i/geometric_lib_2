# Библиотека Geometric Lib

**Geometric Lib** — библиотека для вычисления площадей и периметров геометрических фигур.

## Описание функций

### 1. Круг (`circle.py`)
* `area(r)`: Возвращает площадь круга. Пример: `area(5)` -> `78.5398`
* `perimeter(r)`: Возвращает длину окружности. Пример: `perimeter(5)` -> `31.4159`

### 2. Прямоугольник (`rectangle.py`)
* `area(a, b)`: Возвращает площадь. Пример: `area(5, 4)` -> `20`
* `perimeter(a, b)`: Возвращает периметр. Пример: `perimeter(5, 4)` -> `18`

### 3. Квадрат (`square.py`)
* `area(a)`: Возвращает площадь. Пример: `area(5)` -> `25`
* `perimeter(a)`: Возвращает периметр. Пример: `perimeter(5)` -> `20`

### 4. Треугольник (`trisangle.py`)
* `area(a, h)`: Возвращает площадь. Пример: `area(5, 4)` -> `10.0`
* `perimeter(a, b, c)`: Возвращает периметр. Пример: `perimeter(3, 4, 5)` -> `12`
